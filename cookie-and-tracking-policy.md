# Cookie & Tracking Technologies Policy

**Last updated: 21 November 2026**

Desi Ladki is an Android app, not a conventional browser website. Mobile SDKs and device technologies can perform functions similar to cookies or tracking technologies.

## 1. Current advertising status

The app's Android manifest currently contains Google's AdMob **test** application ID. The developer has confirmed that no AdMob account has been created and production advertising is not yet configured. This means the app should not be described as currently serving production AdMob ads based only on the test application ID.

Before production advertising or analytics is enabled, the operator must verify the SDKs included in the release, advertising identifier access, consent requirements, personalisation settings and data shared with Google. This policy and the Google Play Data safety form must be updated before that functionality is released.

## 2. Other technologies

The app uses network communication for purchase verification and paid session management. The backend uses an anonymous installation identifier and stores purchase/session records. This is not a browser cookie, but it is information associated with an app installation.

## 3. Website

The policy website is a static GitHub Pages site. The supplied page does not intentionally add first-party analytics scripts or advertising cookies. GitHub may process technical logs and operate its hosting infrastructure under its own policies.
